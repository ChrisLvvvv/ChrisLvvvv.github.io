# Redesign Docs

This folder tracks the non-visual groundwork for the portfolio redesign.

- `content-map.md`: where content currently lives, what owns each primary section, and what is tightly coupled to the current theme.
- `redesign-notes.md`: practical notes for the MUJI-inspired portfolio direction and phase boundaries.
- `stack-assessment.md`: keep-or-migrate recommendation for the current Jekyll setup.

The goal of these docs is to make future redesign work easier without losing existing content.
