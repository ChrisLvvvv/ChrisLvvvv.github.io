This course provides a broad introduction to Electrical, Computer and Systems Engineering through hands-on laboratories spanning sensing, embedded control, digital logic, signal processing and machine learning. The labs build practical intuition for core ECSE disciplines and emphasize system-level thinking.

## Skills and Topics Covered

### Sensing and Embedded Interaction
- Interfaced ultrasonic distance sensors and designed LED-based distance indicators.  
- Performed power consumption measurements on DC motors and evaluated efficiency under varying loads.  
- Built embedded control routines for smart-car platforms using microcontroller GPIO and timing functions.

### Control Systems and Robotics
- Implemented **PID control** of a DC motor model in Simulink, tuning Kp/Ki/Kd for stability and transient response.  
- Developed a **lane-keeping controller** for an autonomous smart car using visual feedback and PID-based steering correction.  
- Used step responses, error tracking and closed-loop simulation to evaluate controller robustness.

### Digital Logic and Computing Fundamentals
- Designed combinational logic circuits (adders, decoders, comparators) using Boolean algebra and truth tables.  
- Built sequential logic circuits including counters, registers and FSMs.  
- Analyzed timing diagrams and propagation delays.

### Image Processing and Machine Learning
- Applied classical image processing for traffic sign segmentation and preprocessing.  
- Built a simple **traffic sign classifier** using machine learning pipelines, evaluating accuracy and dataset preparation.  
- Explored feature extraction, thresholding and detection sensitivity.

### Communication and Signal Processing
- Modeled an **AM communication system** in Simulink and analyzed modulation/demodulation performance.  
- Evaluated bandwidth, distortion and filter effects.

## Tools and Platforms
- **Simulink / MATLAB**: modeling DC motors, controls and communication systems  
- **Embedded C**: GPIO control and smart-car programming  
- **Sensors**: ultrasonic distance sensor, DC motor tachometry  
- **Digital logic**: schematic design and timing analysis  
- **Machine Learning**: classical ML workflows for image classification  

## Outcome
These labs provided a broad foundation across the ECSE curriculum, integrating sensing, embedded systems, control theory, digital logic, communication and machine learning. The experience established strong intuition for system-level engineering and prepared the groundwork for advanced coursework and research in embedded systems, robotics and computer hardware.
