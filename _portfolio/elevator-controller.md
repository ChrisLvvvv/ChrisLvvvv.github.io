This project implements a simplified 4-floor elevator controller as an early hardware design exercise. The controller determines whether to remain on the current floor, move up or move down based on a floor request provided through switches. LEDs display movement direction and a 7-segment display shows the elevator’s position.

## My Contribution

- Designed the finite state machine for floor transitions  
- Implemented combinational logic for direction control and display driving  
- Built and verified a working hardware prototype on a protoboard  
- Simulated the full design in LogicWorks before hardware construction  

## Technical Summary

- **Concepts:** Sequential logic, combinational decoding, FSM design  
- **Inputs:** Floor request via switches  
- **Outputs:** Up/down LEDs, 7-segment display  
- **Tools:** LogicWorks, protoboard, discrete logic ICs  

## Outcome

Completed a fully working controller demonstrating core principles of digital logic and early skills in hardware design and verification.
