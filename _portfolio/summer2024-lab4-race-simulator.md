## Process creation and races

I developed multiprocess C programs using fork and exec to examine process creation and race conditions in Linux. The experiments focused on how independently executing processes interact with program control flow.

## Inline assembly

I implemented inline x86 assembly variants of a Collatz computation to investigate instruction-level trade-offs. This paired C-level program structure with explicit assembly operations.
