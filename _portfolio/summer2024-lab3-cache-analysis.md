This project explores cache behavior through analysis of memory access traces. The work examines miss rates, access patterns and the impact of cache size and organization on overall performance.

## My Contribution
- Interpreted memory traces and applied cache policies to compute hit and miss patterns  
- Evaluated total misses, compulsory behavior and replacement effects  
- Summarized performance trends across different traces  

## Technical Summary
- **Concepts:** cache mapping, replacement effects, miss classification  
- **Tools:** custom scripts and analytical breakdown  
- **Input:** memory access trace  

## Outcome
Produced a clear summary of cache performance trends and memory hierarchy behavior, reinforcing understanding of architectural bottlenecks.
